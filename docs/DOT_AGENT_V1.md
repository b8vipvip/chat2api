# Dot D 轨道（#974）
本阶段为 D-01 / D-02 基础切片，不是完整自主 Agent。
注册账户从 Web Chat 左侧“我的 Dot”进入，选择已授权文本模型、配置职责、保存任务、点击执行。服务端复用 Mode 1 统一 Key、模型权限、配额与 Worker adapter。结果保存于 data_dir/dot_v1.sqlite3，不保存 Cookie 或 API Key。每用户最多 100 条任务、一次执行一个；任务创建幂等，租约防重复执行，过期标为 interrupted，不自动重复调用。删除非运行任务可释放空间。
目前需保持执行请求连接；没有后台调度、自动工具循环、主动任务、云电脑或终端。真实 Worker、请求终态恢复、取消、调度、长期记忆及账户删除联动仍须 #974 继续开发与验收。
