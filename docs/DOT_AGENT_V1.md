# Dot D 轨道（#974）
注册账户从 Web Chat 左侧“我的 Dot”进入，选择已授权文本模型、配置职责、保存任务并提交后台执行或一次性定时执行（最多延迟30天）。关闭浏览器不影响服务端执行。每用户最多100条记录；同一 SQLite 数据库全局并发1，SQLite 原子领取（含多执行器争抢）；未领取的任务重启继续。待调度任务可暂停/恢复，执行中的停止仅请求 Worker 取消，最终状态以真实终态为准。服务端不保存 Cookie/API Key，执行前重新检查账户启用状态、共享 Key 和模型授权，沿用 Mode 1 配额。已发起模型请求不会自动重放；重启后根据原请求 ID 及归属对账，超过租约仍无确定结果才标记中断。尚不支持执行中暂停、多步骤检查点、循环调度、长期记忆、插件、云电脑、沙箱。生产真实 Worker 与恢复联动仍需验收。
