# chat2api v0.22.73

## FDEX / Codex strict API FIFO

- Replace the bounded 450 ms sequential handoff heuristic with a terminal-aware FIFO lane per logical API key.
- Keep every request for one logical API key on Worker #1 and the same routed Chrome tab/window. A later request waits until the prior request emits a terminal event instead of spilling into `::worker2` / `::worker3`.
- Keep different logical API keys independent so unrelated APIs can still execute concurrently.
- Cancel requests that are still queued without ever submitting them to ChatGPT.
- Emit explicit `extension_api_fifo` and Worker v28 diagnostics so request history can prove queue position, wait time, worker index, tab id and window id.

## Responses tool bridge

- Promote the tool-stream normalizer to v118.
- Accept the exact equivalent nested custom identity `functions.exec` when the outer call is `namespace=functions, name=exec`.
- Preserve fail-closed behavior for genuinely different nested tool names or namespaces.

## Deployment / versions

- Server Runtime: `0.22.73`.
- Chrome Worker Bundle: `0.8.29`.
- Chrome Bridge wire protocol: `0.8.1`.
- Python package: `0.7.1`.

The Worker Bundle version is intentionally bumped because this release changes `chrome_extension/` code. Linux Worker synchronization can therefore detect an explicit bundle-version mismatch instead of relying only on source fingerprint/commit comparison.
