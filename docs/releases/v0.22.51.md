# chat2api v0.22.51

- Server Runtime: `0.22.51`
- Chrome Worker Bundle: `0.8.21`
- Bridge Protocol: `0.8.1`

## 修复 / Fixes

1. Worker 列表“当前占用”的分母改为浏览器当前真实打开的 ChatGPT **窗口**数量，优先使用 `reserve_window_all_chatgpt_windows`，不再优先显示仅受管的 reserve/warm/route 窗口数。
2. Reserve Pool 的常规 `extension.status` 也持续上报 `reserve_window_all_chatgpt_windows`，不再只有 `windows.snapshot` / `workers.resize` 控制响应才携带该字段。
3. 新增 Window Truth v83：Worker 初始化/登录权威 ChatGPT tab 在受管 Worker 窗口可用后会移动到其中一个 Worker 窗口内，而不是永久单独占用第四个 ChatGPT 窗口。初始化 tab 仍然保留，登录检测语义不变，但与 Worker tab 共享同一个 Chrome window。
4. 浏览器实际仍有额外 ChatGPT 窗口时，控制台会如实显示，例如 `0 / 4`；完成初始化窗口压缩后，备用目标为 3 且无额外 routed/manual ChatGPT 窗口时应稳定为 `0 / 3`。

## 兼容性说明 / Compatibility

“备用窗口”仍是 spare target：正在处理请求或保留短期 route 时，可以暂时出现 `target + routed` 的总受管窗口数。v83 修复的是长期独立存在、却不计入受管池的初始化 ChatGPT **窗口**；它不会牺牲并发槽位，也不会把初始化 tab 用作请求页。
