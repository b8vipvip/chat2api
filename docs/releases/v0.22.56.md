# chat2api v0.22.56

发布日期：2026-09-04

## 版本

- Server Runtime：`0.22.56`
- Chrome Worker Bundle：`0.8.26`
- Chrome Bridge wire protocol：`0.8.1`
- Python package：`0.7.1`

## 主要变更

- Worker 浏览器窗口调度由 v88 最终 authority 统一决定：所有已就绪 warm / reserve 窗口按真实开启时间 FIFO 排序，优先领取最早开启且可接待的窗口。
- 窗口从创建开始即登记稳定编号与 `加载中` 状态，随后进入 `可接待`、`正在调用`、`已关闭` 生命周期；控制台新增「窗口管理」、截图和请求 ID 关联。
- 成功网络终态改为单调终态，后续 synthetic cancel/error 不再把已成功请求降级并触发窗口回收；成功 route 保持既有五分钟保护租约。
- 多 KB Prompt 使用 v88 bounded direct-text 写入，避免 contenteditable `execCommand(insertText)` 产生分钟级同步阻塞。
- 正式发布审查额外修复 programmatic bootstrap / runtime preflight 缺少 v88 terminal/prompt guard 的问题；热修复或 reload 后的页面必须验证 v88 guard 才能视为当前 Worker runtime。

## 发布验证

正式发布要求 Python compile、JavaScript syntax、Linux Worker shell syntax、VM contracts、完整 pytest、Production image smoke 与主分支 Release workflow 全部通过后才创建 `v0.22.56` GitHub Release。
