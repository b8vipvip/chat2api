# chat2api v0.22.50

- Server Runtime: `0.22.50`
- Chrome Worker Bundle: `0.8.20` (unchanged)
- Bridge Protocol: `0.8.1` (unchanged)

## 修复 / Fixes

- Worker 列表“当前占用”的分母改为 Worker 最新实时上报的真实受管 ChatGPT 窗口数量。真实数量为 `0` 时显示 `0`，不再回退到并发设置上限；窗口数量以绿色强调。
- 修复视觉/文件请求在 Worker 下载附件前即失败的问题。中文/Unicode 文件名此前直接写入 HTTP 响应头，Starlette 在 latin-1 头编码阶段抛出 `UnicodeEncodeError`，导致 `/api/extensions/files/{file_id}` 返回 HTTP 500，外层聊天请求最终返回 502。
- v82 下载边界使用 ASCII 安全 fallback、RFC 5987 `filename*` 和 percent-UTF8 扩展头，在保留原始文件名信息的同时保证 HTTP 头可编码。
- 请求诊断中的 `server_version` 重新由 Runtime Contract 统一盖章，避免历史 v21.1 中间件把当前运行时错误显示为 `0.21.1`。

## Validation

新增回归测试覆盖 Unicode 附件响应头可编码性、v82 扩展下载路由替换、Worker 真实窗口数量为 0 时不回退并发上限，以及 Runtime `server_version` 所有权。
