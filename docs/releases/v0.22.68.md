# chat2api v0.22.68

## 支付接口分层

支付配置正式拆分为两类：

- **聚合支付**：ZPAY。管理员必须分别启用支付宝、微信支付；用户费用中心只展示被勾选且配置完整的支付方式。
- **官方/独立支付**：PayPal 与 USDT。PayPal 使用官方 Orders v2 API；USDT 使用管理员自己的欧意 TRON (TRC20) 收款地址。

## PayPal

- 独立总开关，不与 ZPAY 支付宝/微信开关混用。
- 支持正式环境与 Sandbox。
- Client Secret 加密保存，读取配置时不返回明文。
- 服务端完成 OAuth、创建订单、用户批准后的 capture 与金额校验，成功后幂等入账。

## USDT

- 固定网络为 **TRON (TRC20)**，防止用户误选 ERC20/BEP20 等网络。
- 管理员可配置欧意 USDT-TRC20 收款地址、二维码图片 URL、地址链接。
- 用户充值时展示按当前 USD/CNY 计费汇率换算并冻结在订单上的 USDT 金额。
- 用户转账后提交 64 位 TRON TXID；订单进入待核验状态。
- 管理员必须核对欧意账户或链上到账、收款地址、网络、金额与 TXID 后才能确认入账。
- 同一个已入账 TXID 禁止用于第二个订单，避免重复充值。

## 安全

- ZPAY 商户密钥与 PayPal Client Secret 使用服务端 `data_secret.key` 派生的 Fernet 密钥加密落盘。
- 用户端支付方式接口只返回当前可用的公开支付信息，不返回任何商户密钥。
- PayPal/USDT 支付失败不会绕过现有钱包与幂等结算边界。
