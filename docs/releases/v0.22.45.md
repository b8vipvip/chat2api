# chat2api v0.22.45 / Worker 0.8.17

This release formally seals the validated hotfix line after v0.22.44.

## Version surfaces

- Server Runtime: `0.22.45`
- Chrome Worker Bundle: `0.8.17`
- Chrome Bridge protocol: `0.8.1` (unchanged compatibility surface)
- Python package: `0.7.1` (unchanged)
- Content runtime epoch: `71`
- Current request/response epoch: `69`

## Included stabilized hotfixes

- bounded Worker presentation v66 and unified Worker column registry v67;
- resilient multimodal upload v68 and API-key console editor v68;
- exact rich ChatGPT response serialization and request/response epoch v69;
- stale Linux Worker content runtime hot-heal and readiness contract v71;
- all compatibility, rate-limit, network recovery, capacity, Worker authority, and lifecycle guards already present in v0.22.44 remain enabled.

Worker `0.8.17` is a real bundle boundary: manifest, legacy v48 bundle marker/contract, v71 marker/contract, and background runtime preflight all require `0.8.17`. This prevents a same-version `0.8.16` service worker from being mistaken for the formally sealed bundle while preserving the v71 hot-heal path for already-open ChatGPT tabs.
