## Changes

- The request-v6 media completion guard can audit a positively verified current reply and its fresh completion action. User-prompt blocks outside that reply no longer block its media completion. Active generation, recent SSE, stale actions, page-wide/user-contaminated scopes, trailing reply content, and unrelated detached images retain their safeguards.
- Native binding recognizes the complete roleless assistant DIV when its completion toolbar is a sibling. It does not promote their shared user/assistant ancestor. Binding phase/evidence now survive the broker's terminal diagnostic allowlist.
- Worker capture, server validation and admin preview consistently support 64 levels; private DOM evidence supports the corresponding wrapper depth. The admin preview now shares the 8,192-child limit already used by capture/server validation. Node, text, image and byte budgets remain enforced; no partial native tree is accepted.
- A newly created JSON export Blob after a verified same-request `.json` download click supports charset MIME parameters and valid JSON bytes carried as `text/plain` or `application/octet-stream`. Unarmed/inline network JSON, invalid JSON and MIME-less ambiguous blobs remain ineligible. This covers a concrete missing-event path; the uploaded log alone does not prove which browser mechanism produced its original failed clicks.
- Server/Chrome bundle/preflight/admin cache identifiers and their version assertions are synchronized to 0.22.261.
