# chat2api v0.22.57

## 控制台导航卡死热修复

本版本修复 v0.22.56 中管理员控制台在连续切换侧边栏页面后可能完全无响应、同时浏览器控制台没有 JavaScript 异常的问题。

根因不是接口报错，而是浏览器主线程被持续 DOM 重扫和生命周期未收敛的后台刷新占满：`admin_request_device_identity_v47.js` 又出现了对 `document.body` 的全局递归 `MutationObserver`，任何异步列表重绘都会触发新的 TreeWalker 文本规范化；同时 v88 窗口管理页面保持永久 2.5 秒定时器，请求离开页面后也没有主动中止。

本版本恢复此前控制台卡死修复所要求的边界：只保留请求表格的窄范围观察器，静态页面仅规范化一次，异步内容只在 API 完成/导航事件后做一次合并刷新；窗口管理改成仅页面激活时递归调度，离开页面或浏览器标签隐藏时立即停止，单次刷新增加 8 秒 AbortController 上限并复用同一个 in-flight 请求；请求 ID 不再由后台永久计时器反复重绘；窗口管理同时同步 URL hash，避免不同控制台层对“当前页面”的判断不一致。

版本面：

- Server Runtime / Console: `0.22.57`
- Chrome Worker Bundle: `0.8.26`
- Chrome Bridge wire protocol: `0.8.1`
- Python package: `0.7.1`

Worker 浏览器扩展没有协议或内容包变化，因此无需把 Worker Bundle 从 `0.8.26` 再升版；本次属于服务端控制台热修复。
