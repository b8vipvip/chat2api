# chat2api v0.22.74

Server Runtime `0.22.74` and Chrome Worker Bundle `0.8.30` replace the layered same-API/window routing stack with explicit single ownership.

## Request admission

- `server-single-authority-scheduler-v58` is the final broker admission owner.
- One logical API key may have exactly one active request; later requests for the same key wait FIFO on the server.
- Different logical API keys may use the same Worker concurrently up to the configured Worker concurrency.
- Chrome no longer owns a second same-key FIFO.
- The historical v57 per-key concurrency control is compatibility-only and reports a fixed per-key limit of one.

## Browser route and window ownership

- `conversation_routing.js` revision 30 is the sole API route/window lifecycle authority: create, reuse, rotate, retire and idle-close.
- `conversation_dispatch.js` is transport-only and delegates route failure retirement to the router.
- `background_window_observer_v90.js` is observation/capture-only and keeps the existing Window Management surface compatible without allocating, closing, rerouting or protecting windows.
- The production background entry no longer imports warm pool, external warm, reserve pool, tab supervisor, v25/v27/v28 browser worker allocators, v29 browser FIFO, route quarantine, request-recovery window recycler, v88 Window Manager or v111 routed-window cap.
- Capacity controls do not resize browser windows. Worker concurrency is a server scheduling limit; route windows open on demand.
- Worker disable requests route retirement through the router authority instead of independently closing windows.

## Worker runtime alignment

- Chrome Worker Bundle: `0.8.30`.
- Manifest, v48/v71 bundle markers, v48/v71 content contracts and bounded runtime preflight all require `0.8.30`.
- No speculative warm/reserve windows are part of the production request path.

## Production validation

The production-image smoke verifies the generated `linux-worker-bundle.tar.gz` SHA-256, checks that the tar contains the v30 router/transport and v90 observer, asserts retired decision-owner scripts are not imported by the production entrypoint, syntax/contract checks the new runtime, and boots `app.entry:app` to verify `/version` reports Server Runtime `0.22.74` and Worker Bundle `0.8.30`.

Responses Tool Stream v118 and the existing multimodal/native-tool content stack are carried forward unchanged.
